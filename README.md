# Mery' Hairdresser — Official Website

High-conversion luxury website for a Naples-based hair salon.
Designed from scratch with custom branding, color palette and layout.

## Features
- Fully responsive single-page design (HTML/CSS/JS, zero dependencies)
- Hero section with animated stats card
- Interactive service catalog (6 categories)
- Tabbed price list with wellness packages
- Calendly embedded booking widget (per-service event routing)
- Google Calendar auto-sync + email confirmations for both parties
- WhatsApp floating CTA
- Scroll-triggered fade-in animations
- Italian language / Naples market

## Stack
HTML5 · CSS3 (custom properties) · Vanilla JS · Calendly Widget API
Fonts: Cormorant Garamond + Jost (Google Fonts)
